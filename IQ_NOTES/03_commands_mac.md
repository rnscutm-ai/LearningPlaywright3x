# VS Code Keyboard Shortcuts — macOS

## General

| Action | Shortcut |
|--------|----------|
| Command Palette | `⇧⌘P` |
| Quick Open (File) | `⌘P` |
| Settings | `⌘,` |
| Keyboard Shortcuts | `⌘K ⌘S` |
| Toggle Sidebar | `⌘B` |
| Toggle Terminal | `` ⌃` `` |
| Toggle Full Screen | `⌃⌘F` |
| Zen Mode | `⌘K Z` |
| Close Window | `⌘W` |
| Close All Tabs | `⌘K W` |

## Extensions & Help

| Action | Shortcut |
|--------|----------|
| Extensions Sidebar | `⇧⌘X` |
